## 💡 If Asked Follow-Up Questions

**Q: How is this different from existing launchpads?**
A: Current launchpads use one exponential curve optimized for memes. We provide 4 specialized curves — one for each asset class. Our innovation is using DBC's RateLimiter for equity/RWA price discovery.

**Q: What's the market opportunity?**
A: $2B+ tokenized equities market + $10B+ RWA market. Both need fair, slow price discovery. Solana's launchpads don't support this today. Aequus solves that.

**Q: How does RateLimiter work for equities?**
A: Instead of fees scaling with time (like traditional schedulers), fees scale with buy SIZE. A whale can't gap the price in one block. Fair discovery over hours.

**Q: Is this production-ready?**
A: Yes. Built with real Meteora DBC SDK. Tested parameters. Live migration path to DAMM v2. Can deploy to testnet today.

**Q: How do you monetize?**
A: Premium presets (Stock Discovery, RWA Steady) cost 2 SOL each. Free presets (ICM Fast, Meme Classic) drive adoption. Marketplace model.
