## **Project Description**

Aequus is a professional bonding curve preset marketplace built on Meteora's Dynamic Bonding Curve infrastructure. It provides 4 expertly-tuned curve configurations for different asset classes:

1. **Stock Discovery** — Slow, size-aware pricing for tokenized equities
2. **RWA Steady** — Near-flat curves for real-world assets (NAV tracking)
3. **ICM Fast** — Fast launches with anti-bot fee protection
4. **Meme Classic** — Standard baseline for comparison

**Key Innovation:** Repurposes DBC's RateLimiter as a price-discovery mechanism (fees scale with buy size, not time).

**Features:**
- Interactive preset explorer with modal previews
- Solana wallet integration (ready for deployment)
- Professional UI with full responsive design
- End-to-end flow from config → launch → DAMM v2 migration
- Production-ready code with real SDK integration

**Why it matters:** Current launchpads use one-size-fits-all exponential curves. Aequus enables asset-class-specific launches, solving a real problem for equities, RWAs, and other serious assets.
