4. PROJECT DESCRIPTION
────────────────────────────────────────────────────────────────────────────
Aequus is a professional bonding curve preset marketplace built on Meteora's 
Dynamic Bonding Curve (DBC) infrastructure. It solves a critical problem: all 
launchpads use the same exponential curve, even though tokenized equities, 
real-world assets (RWAs), and memes need fundamentally different mechanics.

Aequus provides 4 expertly-tuned, production-ready presets:

• Stock Discovery (2 SOL) — Slow, size-aware price discovery for tokenized 
  equities using novel RateLimiter innovation (fees scale with buy size, not time)
  
• RWA Steady (2 SOL) — Nearly-flat curves for real-world assets that track NAV 
  instead of speculating
  
• ICM Fast (Free) — Steep exponential with aggressive anti-bot fees for fast 
  internet-capital-markets launches
  
• Meme Classic (Free) — Standard baseline so all presets can be compared against 
  a known reference

KEY FEATURES:
✓ Interactive preset explorer with modal previews
✓ Solana wallet integration (ready for deployment)
✓ Professional, fully responsive UI
✓ Deploy button with success confirmation
✓ End-to-end flow: Config → Launch → Monitor → Migrate to DAMM v2
✓ Production-ready code with real SDK integration

KEY INNOVATION:
Repurposes DBC's RateLimiter (anti-sniper tool) as a price-discovery mechanism. 
This enables equities and RWAs to find fair prices without explosive volatility 
that's typical of exponential curves.

MARKET OPPORTUNITY:
• Tokenized equities: $2B+ market
• RWA space: $10B+ projected
• Multiple use cases: equity platforms, RWA issuers, DAOs, launchpads

WHY AEQUUS WINS:
1. Solves a real, unaddressed problem
2. Novel use of DBC technology (not just for memes)
3. Marketplace model (premium presets subsidize free ones)
4. Production-ready, not theoretical
5. Extensible (builders can add custom presets)

PRESET CONFIGURATIONS (for technical judges):
──────────────────────────────────────────────

Stock Discovery:
  - 6 price checkpoints (long curve)
  - RateLimiter fee mode (size-based, not time-based)
  - Migration fee: 200 bps
  - Use case: Tokenized equities, slow discovery

RWA Steady:
  - 4 price checkpoints (nearly flat)
  - Linear fee mode (constant)
  - Migration fee: 25 bps
  - Use case: NAV-tracking real-world assets

ICM Fast:
  - 3 price checkpoints (steep exponential)
  - Fee scheduler: 90% → 1% over 60 periods
  - Migration fee: 100 bps
  - Use case: Fast launches with anti-bot protection

Meme Classic:
  - 4 price checkpoints (standard exponential)
  - Fee scheduler: 9000 → 120 bps over 60 periods
  - Migration fee: 120 bps
  - Use case: Reference baseline, meme tokens
